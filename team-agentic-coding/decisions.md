## 2026-08-06 — Keep this brainstorm in-repo as Markdown

**Decision:** Findings and decisions live as Markdown in `team-agentic-coding/`, in git,
rather than in Notion/Docs.

**Why:** The agents we're reasoning about read the repo. If our conclusions about how to
work with agents aren't readable *by* those agents, we've built a doc no one uses. Git
also gives us the diff history, which is the actual record of how our thinking changed.

**Would change our mind:** If non-engineers need to participate heavily, the friction of
git may outweigh the co-location benefit.
